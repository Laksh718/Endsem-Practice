# DM Practice MCQ

OMR-style practice site for SRM IST past-year papers:

- Discrete Mathematics (21MAB302T), 99 Part A questions from 5 papers
- Formal Language and Automata (21CSC301T), 92 Part A questions from 5 papers

Features: paper and question tags, topic repeat frequency, hot topics ranking, Part B/C pattern table,
practice and exam modes, retry mistakes (saved in the browser), and diagram questions with the original figure.

Answers were worked out from scanned papers and are not an official key.

## Run locally
Open `index.html` in a browser. No build step.
